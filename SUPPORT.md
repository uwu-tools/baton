# Support

## Getting Help

Thanks for using `baton`! Here are some ways to get help:

### Documentation

- [README](README.md) — project overview and usage
- [docs/design.md](docs/design.md) — the file format, states, probes, and
  threat model
- [CONTRIBUTING](CONTRIBUTING.md) — how to contribute

### Issues

If you've found a bug or have a feature request:

1. Search [existing issues](https://github.com/uwu-tools/baton/issues) first
2. If not found, [open a new
   issue](https://github.com/uwu-tools/baton/issues/new/choose)

### Security Issues

**Please do not report security vulnerabilities through public issues.**

See our [Security Policy](SECURITY.md) for responsible disclosure instructions.

## Response Times

This is an open source project. Response times may vary based on maintainer
availability. We appreciate your patience!

## Support Scope

| Version | Status  | Support Duration |
| ------- | ------- | ---------------- |
| latest  | Preview | Current release  |

`baton` is pre-1.0; the file format and commands may change between minor
releases. Support covers the latest release.
